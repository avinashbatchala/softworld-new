## 🎯 Design System

### Color Palette (Grayscale Only)
```
Backgrounds:
- #0A0A0A (Pure Black - Main background)
- #111111 (Dark Gray - Elevated surface)
- #1A1A1A (Lighter Gray - Higher elevation)

Borders:
- #222222 (Subtle border)
- #333333 (Border on hover)

Text:
- #FFFFFF (White - Primary text)
- #A0A0A0 (Light Gray - Secondary text)
- #666666 (Medium Gray - Tertiary text)

Accents:
- #FFFFFF (White - All interactive highlights)
- #E5E5E5 (Light Gray - Dimmed state)
- #D4D4D4 (Very Light Gray - Gradient end)
```

### Visual Effects
- **Glow**: `box-shadow: 0 0 20px rgba(255, 255, 255, 0.2)`
- **Elevation**: Subtle shadows with rgba(0, 0, 0, 0.4-0.8)
- **Blur**: `backdrop-filter: blur(10px)` for glassmorphism
- **Transitions**: `0.3s cubic-bezier(0.4, 0, 0.2, 1)`
